# Отчёт по автоматизации

## 1. Что было запланировано и что реализовано
**Запланировано:**
- Автоматизация позитивных и негативных сценариев оплаты дебетовой картой.
- Проверка UI и базы данных.
- Интеграция Allure для отчётов.
- Оформление документации.

## Причины, по которым что-то не было реализовано
- Не реализованы тесты для кредитной оплаты (запланированы, но не успели).
- Не добавлены проверки дополнительных валидаций (год, месяц, CVC)– они покрыты в негативных сценариях частично.

## Сработавшие риски
- **Сложность с настройкой окружения** (Docker, драйвер Chrome на M1)  — на это ушло больше времени, чем планировалось (вместо 4 часов — 10 часа).
- **Нестабильность селекторов** (динамическая подгрузка элементов) — пришлось несколько раз переписывать XPath из-за динамической подгрузки элементов.
- **Проблемы с драйвером Chrome** — из-за архитектуры M1 пришлось вручную устанавливать Chromedriver.

## Ключевые цифр
- **Всего тестов:** 13
- **Успешных (PASSED):** 9 (69%)
- **Ожидаемо падают (XFAIL):** 2 (баги валидации)
- **Падают из-за критических багов:** 2 (отсутствие уведомлений)

- В итоге общее время увеличилось на **3 часа** относительно плана.

## 5. Результаты тестирования (основные баги)
1. Нет уведомлений об успехе/ошибке после оплаты.
2. Валидация пропускает кириллицу в поле "Владелец".
3. Валидация CVC не проверяет длину.
4. Пустой номер карты выдаёт "Неверный формат" вместо "Обязательное поле".

## 6. Рекомендации
- **Приоритетно исправить отображение уведомлений** после отправки формы – добавить компонент `.notification` с явными статусами (успех/ошибка) и текстовыми сообщениями, чтобы пользователь сразу видел результат операции.
- **Улучшить валидацию полей "Владелец" и "CVC"** на стороне клиента и сервера – настроить проверку допустимых символов (только латиница для владельца) и длины (ровно 3 цифры для CVC), чтобы исключить отправку некорректных данных.
- **Добавить информативные сообщения об ошибках** для пользователя – заменить общие формулировки на конкретные подсказки (например, "Поле обязательно для заполнения", "Введите 3 цифры CVC"), чтобы упростить исправление ошибок.
- Расширить автоматизацию на кредитные сценарии и оставшиеся валидации после исправления багов.

## Выводы
Автоматизация выполнена **частично** 
– основные сценарии оплаты дебетовой картой покрыты, но не все.
